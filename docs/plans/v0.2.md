# v0.2 plan

Tracks v0.2 scope. Items move from this file to `CHANGELOG.md` as they ship.

## Recon findings (recorded so we don't relearn)

- **HOLA does not honor `add_node(x=, y=)` as a pin.** Smoke-tested
  2026-05-02: requested A at `(500, 500)`, HOLA placed it at `(0, 112)`.
  `HolaOpts` has no pin/anchor option (only ACA constraints, padding,
  aspect ratio, tree-layout knobs). True pinning would require post-layout
  translation of matched-component blocks, which fights HOLA's layout
  coherence. **HOLA pinning deferred to v0.3** — needs design work.
- **libavoid Python binding still doesn't exist** (re-confirmed at v0.1
  release). Pure-Python obstacle-aware L-shape stays the router for v0.2.

## v0.2 scope

### 1. `--placer auto` with HOLA-then-naive fallback

**Why:** HOLA aborts gracefully on 3 fixtures; the user currently has to
know which placer to pick. `auto` tries HOLA first, falls back to naive
on `PlacerEngineError`.

**Where:** `src/wirewright/placers/__init__.py` — register an `AutoPlacer`
that delegates. CLI `--placer auto` becomes the recommended default.

**Estimate:** ~30 min.

### 2. Manual-edit diff loop (`wirewright diff`)

**Why:** This was the original justification for the project — render via
HOLA, edit `.asc` to taste in LTspice, feed edits back to learn what the
placer should do differently. The `.asc` parser is built; we just need
the diff layer.

**Behavior:** `wirewright diff <original.asc> <edited.asc>` parses both
files via `parse_asc_text`, computes a structured report:
- Components moved: `R5: (64, 64) → (128, 96)` deltas.
- Components rotated: `Q3: R0 → M0`.
- Wires added/removed (set-diff on wires).
- Pattern-matched groups whose internal layout the user changed (signal
  for "this pattern's template should produce this layout").

**Where:** `src/wirewright/diff.py` (new module), `wirewright diff`
subcommand in CLI.

**Estimate:** 1 session.

### 3. Graph pre-conditioning for HOLA aborts

**Why:** 3 canonical fixtures abort in `faces.cpp::identifyExternalFace`.
Earlier biconnectivity check was too restrictive. Targeted approach:
when HOLA returns `PlacerEngineError`, identify articulation points and
add a virtual edge bridging the cut vertex to its second-degree neighbor;
retry. If still aborts, fall through to `naive` per #1.

**Where:** `src/wirewright/placers/hola.py` — pre-condition step before
the subprocess call.

**Estimate:** 1-2 sessions; uncertain because we don't know exactly which
graph property HOLA wants beyond planarity + connectivity.

### 4. Power/ground as global rails

**Why:** Currently `VDD`/`VSS`/`0` show up as scattered FLAGs at every
pin. Spec calls for horizontal rails at top/bottom of canvas. Visual win,
especially on transistor-heavy fixtures.

**Where:** `src/wirewright/placers/hola.py` post-layout step + naive too.
Compute global Y for each power/ground net, route a horizontal rail
across the canvas, drop FLAGs at the rail (not at each pin).

**Estimate:** 1 session.
