# Project skills

Drop your existing personal skills (spec-n-check, plan-validation, code-audit,
adversarial-review from Superpowers) here as symlinks or copies. They will
apply to this repo automatically.

Suggested:

- `spec-n-check/` - run after any spec change in `docs/specs/`
- `plan-validation/` - run when modifying `docs/PLAN.md`
- `adversarial-review/` - already mirrored as the `adversarial-reviewer` agent above

Personal skills are not committed to the public repo by default; they live
in your global `~/.claude/skills/` and you symlink the relevant ones in.
